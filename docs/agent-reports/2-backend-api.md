## Risiken / Hinweise
- Rate-Limit und Replay-Speicher im Arbeitsspeicher gelten pro Prozess; bei mehreren Instanzen vervielfacht sich das Limit, ALTCHA-/CSRF-Replay wäre instanzübergreifend möglich (Briefing: eine Instanz).
- Ein Foto mit falschem Format verbraucht das ALTCHA (bewusst: Dekodieren erst nach Arbeitsnachweis). Das Formularskript löst danach automatisch ein neues.
- `TRUST_PROXY=true` nur hinter eigenem Reverse-Proxy setzen, sonst können Clients ihre Kennung per `X-Forwarded-For` wechseln.
- E2E braucht Docker und openssl (in GitHub-Actions-Ubuntu vorhanden). HEIC-Dekodierung lädt beim ersten HEIC-Upload ca. 1,5 MB WASM (einmalig je Prozess).
